# MathNote

普通のテキストエディタに、テキストのままでは表せない**二次元の配置**だけを書き足せるようにした
メモ帳です。罫線とその上下・ルートなどはキー操作／パレットで入れられ、記法を手で覚える必要は
ありません。構文ハイライトや装飾機能は持ちません。

- Tauri v2 + Leptos（Rust のみ、TypeScript なし）
- 構造の描画は自作（外部ライブラリ非依存）
- 保存形式は独自記法のプレーンテキスト（[docs/notation.md](docs/notation.md)）。LaTeX / MathML
  との互換は持たず、HTML / MathML の書き出しもしません
- 構造にするのはテキストでは書けない配置（罫線とその上下・ルート・記号の上下・格子状の並びなど）
  だけで、`|x|` や `×` `≤` `α` `sin` などは普通の文字として本文に入ります
- `.txt` などの通常のテキストファイルもそのまま開いて編集できます
- エディタは `contenteditable` ではなく自前描画（表示・カーソル・選択を自分で描き、入力は画面外の
  textarea で受け取る VS Code 型）なので、カーソルを複数置いて同時に編集できます

## Windows 版のダウンロード

GitHub Actions の `build` ワークフローが `windows-latest` でインストーラを生成します。

- 各コミットのビルド: Actions → 対象の実行 → Artifacts の `mathnote-windows`（`.msi` と `.exe`）
- リリース: `v` から始まるタグ（例 `v0.1.0`）を push すると、同じ成果物が Release に添付されます

## 構造の書き方

本文を打っていると構造に切り替わります。メニューやボタンを使う必要はありません。

| 本文での入力 | 結果 |
| --- | --- |
| `1/` `x/` | 直前の英数字を罫線の上に置いた構造に入る（`and/or` のような語はそのまま） |
| `x^` `x_` | 上付き / 下付き |
| `\sqrt` + スペース | ルート（`\sum` `\int` `\cases` など形を伴うものも同様） |
| `√` + スペース | ルート（`∑` `∫` を直接入力しても同じ） |
| `\alpha` `\sin` + スペース | `α` `sin` という普通の文字になる（構造にはならない） |
| `$` | 空の構造に入る |
| `Esc` | 本文に戻る |

`Ctrl+M` とパレットからも入れられます。

| 構造内の操作 | 入力 |
| --- | --- |
| 罫線とその上下 | `/`（直前の英数字が上になる） |
| 上付き / 下付き | `^` / `_` |
| ルート・記号の上下・格子状の並び | `\sqrt` や `√` + スペース、またはパレット |
| 括弧 | `(` `[` で開き、`)` `]` で外へ出る |
| 行を追加 / 列を追加 | `Alt+Enter` / `&` |
| 入れ子の移動 | `←` `→` `↑` `↓` `Home` `End` `Tab` |
| 構造の削除 | `Backspace`（中身は残して展開） |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` |

対応構造: 罫線とその上下（罫線なしも可）、ルート・n 乗根、上付き・下付き、括弧（`()` `[]` `{}` `||`）、
記号の上下、格子状の並び・場合分け。ギリシャ文字・記号・`sin` などの関数名はパレットから普通の
文字として入ります。保存されるテキストの記法は [docs/notation.md](docs/notation.md) にあります。

## 本文の操作

| 操作 | ショートカット |
| --- | --- |
| 新規 / 開く / 保存 / 名前を付けて保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| タブを増やす / 閉じる / 切り替え | `Ctrl+T` / `Ctrl+W` / `Ctrl+Tab`・`Ctrl+Shift+Tab`（タブ帯のクリックでも） |
| 元に戻す / やり直し（本文と構造を通して） | `Ctrl+Z` / `Ctrl+Shift+Z`・`Ctrl+Y` |
| 検索・置換 | `Ctrl+F`（`Aa` で大文字小文字を区別、`.*` で正規表現、置換は `$1` で後方参照） |
| カーソルを追加 | `Alt+クリック` |
| 同じ語を次々選択 | `Ctrl+D`（ダブルクリックでも語を選択） |
| すべて選択 | `Ctrl+A` |
| 列の区切りを入れる（`=` などを縦に揃える） | `Tab`（記法は `$(t)`。連続する行の区切りが揃う） |

## 開発

必要なもの: Rust stable、`wasm32-unknown-unknown` ターゲット、[Trunk]、[Tauri CLI] v2。
Linux では `libwebkit2gtk-4.1-dev` などの Tauri 依存パッケージも必要です。

```sh
rustup target add wasm32-unknown-unknown
cargo install --locked trunk
cargo install --locked tauri-cli --version "^2"

cargo tauri dev      # 開発起動
cargo test           # 記法とエディタのテスト
cargo tauri build    # インストーラの生成
```

起動時間を測る場合は `MATHNOTE_STARTUP_LOG=1` を設定して起動すると、最初の描画までの ms が
標準エラーに出力されます。

## 制限

解釈するのは上記の対応構造だけです。それ以外は文字として保持されるため壊れませんが、配置はされ
ません。細かな組版規則（イタリック補正、記号ごとのスペーシング）も簡略化しています。

[Trunk]: https://trunkrs.dev/
