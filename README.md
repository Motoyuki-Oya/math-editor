# Planetext

普通のテキストエディタに、テキストのままでは表せない**二次元の配置**だけを書き足せるようにした
メモ帳です。罫線とその上下・ルートなどはキー操作／パレットで入れられ、記法を手で覚える必要は
ありません。構文ハイライトや装飾機能は持ちません。

- Tauri v2 + Leptos（Rust のみ、TypeScript なし）
- 構造の描画は自作（外部ライブラリ非依存）
- 保存形式は独自記法のプレーンテキスト（[docs/notation.md](docs/notation.md)）。LaTeX / MathML
  との互換は持たず、HTML / MathML の書き出しもしません。`$()` は保存時だけの構文で、編集中は
  文字と二次元構造が同じ行の兄弟として並び、島や数式モードには切り替わりません
- 構造にするのはテキストでは書けない配置（罫線とその上下・ルート・記号の上下・格子状の並びなど）
  だけで、`|x|` や `×` `≤` `α` `sin` などは普通の文字として本文に入ります
- `.txt` などの通常のテキストファイルもそのまま開いて編集できます
- エディタは `contenteditable` ではなく自前描画（表示・カーソル・選択を自分で描き、入力は画面外の
  textarea で受け取る VS Code 型）なので、カーソルを複数置いて同時に編集できます

## Windows 版のダウンロード

GitHub Actions の `build` ワークフローが `windows-latest` でインストーラを生成します。

- 各コミットのビルド: Actions → 対象の実行 → Artifacts の `planetext-windows`（`.msi` と `.exe`）
- リリース: `v` から始まるタグ（例 `v0.1.0`）を push すると、同じ成果物が Release に添付されます

## 構造の書き方

本文を打っていると構造に切り替わります。メニューやボタンを使う必要はありません。

| 本文での入力 | 結果 |
| --- | --- |
| `1/` `abc/` `日本/` + スペース | 文字種にかかわらず、直前の連続した文字を罫線の上に置いた構造に入る |
| `x^` `x_` + スペース | 上付き / 下付き |
| `\sqrt` + スペース | ルート（`\sum` `\int` `\cases` など形を伴うものも同様） |
| `√` `√[n]` `∑` `Σ` `∫` + スペース | ルート・n乗根・記号の上下 |
| `\alpha` `\sin` + スペース | `α` `sin` という普通の文字になる（構造にはならない） |
| `Esc` | 本文に戻る |

`Ctrl+M` とパレットからも入れられます。

| 構造内の操作 | 入力 |
| --- | --- |
| 罫線とその上下 | `/`（直前の連続した内容が上になる） |
| 上付き / 下付き | `^` / `_` |
| ルート・記号の上下・格子状の並び | `\sqrt`・`√`・`∑`・`Σ`・`∫` + スペース、またはパレット |
| 対象の上／下に小さい欄を開く | 対象を選択して `Ctrl+↑` / `Ctrl+↓`、またはパレット |
| 括弧 | `(` `[` で開き、`)` `]` で外へ出る |
| 行を追加 / 列を追加 | `Alt+Enter` / `&` |
| 入れ子の移動 | `←` `→` `↑` `↓` `Home` `End` `Tab`（空の上下欄は飛ばす） |
| 構造を抜ける | `Enter` / `Esc`（構造内部では改行しない） |
| 構造の削除 | `Backspace`（中身は残して展開） |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` |

対応構造: 罫線とその上下（罫線なしも可）、ルート・n 乗根、上付き・下付き、括弧（`()` `[]` `{}` `||`）、
任意の文字列や構造の上下、格子状の並び・場合分け。パレットにあるのはこの構造だけで、ギリシャ文字・記号・`sin`
などはキーボードや IME で普通の文字として打ちます。保存されるテキストの記法は
[docs/notation.md](docs/notation.md) にあります。

## 本文の操作

| 操作 | ショートカット |
| --- | --- |
| 新規 / 開く / 保存 / 名前を付けて保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| タブを増やす / 閉じる / 切り替え | `Ctrl+T` / `Ctrl+W` / `Ctrl+Tab`・`Ctrl+Shift+Tab`（タブ帯のクリックでも） |
| 左右に分割 / 解除 | `Ctrl+\`（ペインごとにタブ帯を持ち、解除すると残ったペインにタブが集まります） |
| 元に戻す / やり直し（本文と構造を通して） | `Ctrl+Z` / `Ctrl+Shift+Z`・`Ctrl+Y` |
| 検索・置換 | `Ctrl+F` / 置換は `Ctrl+R`（`Aa` で大文字小文字を区別、`.*` で正規表現。正規表現のときの置換後は `$1` で後方参照、`\t` で列の区切り、`\n` で改行） |
| カーソルを追加 | `Alt+クリック` |
| 同じ語を次々選択 | `Ctrl+D`（ダブルクリックでも語を選択） |
| すべて選択 | `Ctrl+A` |
| 列の区切りを入れる（`=` などを縦に揃える） | `Tab`（連続する行の区切りが縦に揃う） |

メニューは OS のもので、Windows と Linux ではウィンドウ上端、macOS では画面上端に「ファイル /
編集 / 表示 / ヘルプ」として出ます（macOS では設定と終了が「Planetext」メニューに入ります）。
ショートカットはメニューの項目の横に、その OS の書き方で並びます。

「表示」メニューで折り返し（既定: する）と行番号（既定: 出さない）を切り替えられます。どちらも
文書ではなく見え方の設定で、次に起動したときも覚えています。

書いている内容は打つのをやめた少しあとに下書きとして自動で控えられ、次の起動で未保存のタブとし
て戻ります（ファイル自体を書くのは保存したときだけです）。保存すると、その文書の下書きは消えま
す。

## 開発

必要なもの: Rust stable、`wasm32-unknown-unknown` ターゲット、[Trunk]、[Tauri CLI] v2。
Linux では `libwebkit2gtk-4.1-dev` などの Tauri 依存パッケージも必要です。

```sh
rustup target add wasm32-unknown-unknown
cargo install --locked trunk
cargo install --locked tauri-cli --version "^2"

cargo tauri dev      # 開発起動
cargo test           # 記法とエディタのテスト
cargo tauri build    # インストーラの生成
```

起動時間を測る場合は `PLANETEXT_STARTUP_LOG=1` を設定して起動すると、最初の描画までの ms が
標準エラーに出力されます。

## 制限

解釈するのは上記の対応構造だけです。それ以外は文字として保持されるため壊れませんが、配置はされ
ません。細かな組版規則（記号ごとのスペーシング）も簡略化しています。字体は本文と同じで、変数を
斜体にはしません。

[Trunk]: https://trunkrs.dev/
[Tauri CLI]: https://tauri.app/
