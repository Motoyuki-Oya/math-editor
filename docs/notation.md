# MathNote 記法仕様

本文は普通のテキスト。テキストのままでは表せない**二次元の配置**だけを「島」として書く。
LaTeX / MathML との互換は持たない（必要なら後から変換する）。

## 1. 島

```
$( ... )
```

- `$(` で始まり、対応する `)` で終わる。
- 島の中だけで、以下に定める文字が構造として解釈される。
- 島は入れ子にできる。

```
$(√ x$(^ 3 _ i))
```

- 島の外は全て普通の文字。`[a, b; c, d]`・`{}`・`√`・`/` などをそのまま書ける。

### エスケープ

- `$$` … 素の `$` 1 文字。
- `(` は直前が `$` でなければただの文字。`)` も島の中でなければただの文字。
- 島の中では、**その位置で文法上の意味を持つ文字だけ** 2 個重ねて素の文字にする。
  意味を持たない位置ではそのまま書ける。

| 書きたい文字 | 島の中での書き方 |
| --- | --- |
| `/` | `//` |
| `-` | `--` |
| `,` | `,,` |
| `;` | `;;` |
| `[` `]` | `[[` `]]` |
| `$` | `$$` |
| `→` `←` `↔` `⇒` `⇐` `⇔` `⇄` `↦` | `→→` のように 2 個重ねる |

- 矢印はカンマ区切りの引数や行列のセルの中では普通の文字なので、重ねても
  重ねなくても同じ（例: `$(↨ lim,, n→∞)`）。
- ただしカンマ区切りの引数（`$(↨ …)`・`$(/ …)`・行列のセル）の中では、`,,`
  は「空の引数」を表す（例: `$(↨ lim,, n→∞)`）。この位置でカンマそのものを
  書きたいときは括弧で囲む（例: `$(↨ f(a,b), n,)`）。

## 2. 構造一覧

### 2.1 上下（罫線あり）

罫線とその上下。いわゆる分数もこれで書く。

```
$(上/下)
$(/ 上, 下)
```

例:

```
$(1/2)        面積は $(1/2)ah です
$(/ x+1, 2y)
```

### 2.2 上下（罫線なし）

罫線を引かず、ただ上下に積む。

```
$(上 - 下)
$(- 上, 下)
```

例:

```
$(n - k)
$(- n, k)
```

### 2.3 上下（矢印）

罫線の代わりに矢印を引く。矢印は上下の広い方に合わせて伸びる。

```
$(上 → 下)
$(→ 上, 下)
```

使える矢印は `→` `←` `↔` `⇒` `⇐` `⇔` `⇄` `↦`。

例:

```
$(→ f,)          上に f だけ
$(→ , n→∞)        下だけ（引数の中の矢印は普通の文字）
$(x ⇒ y)
```

### 2.4 ルート

```
$(√[n] 中身)
$(sqrt[n] 中身)
```

- `[n]` は省略可。`$(√ x)` は普通のルート。
- `sqrt` は `√` の別名。
- 中身は `√` の直後の 1 かたまり。複数の要素をまとめるときは括弧で囲む。

例:

```
$(√ x)        →  √x
$(√ x) + 1    →  √x + 1
$(√ (x+1))    →  √(x+1) 全体がルートの中
$(√[3] x)     →  3 乗根
$(sqrt[n] a)
```

### 2.5 上付き・下付き

直前の文字（島の直前にある内容）に付く。

```
x$(^ 3)
x$(_ i)
```

同時に付けるときは糖衣構文が使える。

```
x$(^ 3 _ i)      ≡  x$(^ 3)$(_ i)
```

### 2.6 記号＋上下

記号の上と下に何かを置く。Σ に限らず任意の記号（文字列）を置ける。

```
$(↨ 記号, 上, 下)
```

- 区切りは全てカンマ。
- 片方だけのときは空にする。

例:

```
$(↨ Σ, n, x=1)
$(↨ Σ, n,)        上だけ
$(↨ lim,, n→∞)    下だけ
```

### 2.7 行列（格子状の並び）

`[...]` が 1 行、カンマが列の区切り。

```
$([a, b][c, d])
```

- 行数・列数は自由。
- 編集中に行を増やすのは **Alt+Enter**。

### 2.8 場合分け

行列の先頭に `{` を置くと、左に大きい波括弧が付く。

```
$({[x>0, 正][x<0, 負])
```

- 中身の書き方・行追加（Alt+Enter）は行列と同じ。

### 2.9 列の区切り

行の中に `$(t)` を置くと列の区切りになり、**連続する行**の区切りが縦に揃う。
`=` を縦に揃えたいときや、表のように並べたいときに使う。

```
名前 $(t) 年齢 $(t) 所在
大屋 $(t) 30   $(t) 東京

x $(t)= 1 + 2
y $(t)= 3
```

- 揃えるのは連続する行の塊。区切りの無い行や空行で塊が切れる。
- 罫線は引かない。揃えるのは見た目だけで、各行は普通のテキストのまま。
- 他の構造の中（島の中）には置けない。島の中の `$(t)` は普通の文字。
- 編集中は Tab キーで挿入する。素の Tab 文字は区切りにならない（そのままの文字）。

## 3. ファイル

- 拡張子は問わない。テキストファイルであれば何でも開ける（`.txt` など）。
- 開いたテキストの中にこの記法を見つけたら、構造として復元して表示する。
- 保存はこの記法をそのまま書き出す（普通のテキストとして他のエディタでも読める）。

## 4. 空白

- 構造の区切りとして使う位置の空白は無視する（カンマの前後、種別記号の直後、`[n]` の後など）。
- それ以外の空白は、見た目どおりの空きとして残す。

```
$(↨ Σ, n, x=1)   ≡  $(↨Σ,n,x=1)
$(√ x)           ≡  $(√x)
$(a  b)          →  a と b の間に空きが残る
```

## 5. 括弧の高さ

- 中身に合わせて自動で伸縮する。記法では指定しない。
- 将来必要になれば指定を追加できる（既存の書き方は変わらない）。

## 6. 書き出し

- このエディタが書き出すのは、この記法のテキストだけ。
- HTML / MathML への書き出しは行わない。
